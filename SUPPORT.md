# Support

Thanks for using Smoke Monkey Harness. Here's how to get help.

## Documentation first

Start with the docs before opening an issue:

- [README](README.md) — feature overview and quick start
- [docs/getting-started.md](docs/getting-started.md) — installation and first agent
- [docs/api.md](docs/api.md) — API reference
- [docs/providers.md](docs/providers.md) — LLM providers (NVIDIA reference)

## Bugs and feature requests

Open an issue using the appropriate template:

- **Bug report** — reproducible problems
- **Feature request** — new ideas

Include your Node version, package version, package manager, and provider +
model (see the bug template).

- [Issue tracker](https://github.com/RajdeepDevelopment/smoke-monkey-harness/issues)

## Questions

For questions that aren't clearly a bug or feature request (usage, integration,
examples), the issue tracker works as well — label it `question`.

## Security

Found a vulnerability? Do **not** open a public issue — report it privately via
GitHub's Private Vulnerability Reporting (see [SECURITY.md](SECURITY.md)).
